# WorkLyft

Marketing site for [worklyft.com](https://worklyft.com), presenting **Crewlyft** — the business app for company chats, people and news.

## Develop

```bash
cd worklyft
npm install
npm run dev
```

Open [http://localhost:3010](http://localhost:3010).
